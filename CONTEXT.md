# Glass

Glass observes and drives external native applications through visual and accessibility evidence.

## Language

**Actionability**:
The evidence used to decide whether an intended interaction may proceed, including what is proven, failed, or unproven for that operation. Actionability does not establish that input was dispatched or that the application reached the intended state.

**State coverage**:
The accessibility states a backend can establish reliably. An uncovered state is unknown, rather than evidence that the state is false.

**Actionability report**:
An ordered account of actionability checks, with each check's verdict, evidence source, and whether it is required for the interaction.

**Targeted typing**:
Text input addressed to a semantic target, with eligibility evaluated and focus confirmed before text is sent. Being focusable alone does not establish typing eligibility.
